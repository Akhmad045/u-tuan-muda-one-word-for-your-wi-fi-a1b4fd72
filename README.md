## The word

**Ghosting** — home Wi-Fi that vanishes mid-call without a word, like a bad date. Funny at once, true to how Wi-Fi actually behaves, and a fresh angle on the familiar annoyance: not "slow", not "buffering", but gone without saying goodbye. It works as a single word with no context needed — and it would make a perfect network name.

## How it works

`main.py` (Python standard library only, deterministic, no network, no randomness) writes the word to `/output/entry.txt`, validates it against the kit gate (a single word, 1–20 characters, not only whitespace), then reads the file back and compares it with the intended word.

```sh
python3 main.py
```
